Evidence — a hand on every row that moved

Shipped, with one change from the draft: the same avatar marks both states. A Pencil on the edited row was built and rejected — the mark answers whose hand is on this row, and that is the same person either way, so two glyphs made one question look like two. §2 and §5 keep the alternatives for the record; every other section draws what shipped.

Today only a row the reviewer added carries a name. A row they re-weighted carries nothing, which is the more common edit and the one that moves the recommendation. The mark becomes a two-verb grammar — UserRound for added, Pencil for edited — with the same name, ink, size and slot in both, so the column answers one question down its whole length: whose hand is on this row?

2 · Which glyph carries “edited”

The name is identical in both states, so the glyph is the only thing doing the work. It has to read at 12px beside 10.5px type, and it has to pair with the filled UserRound without looking like a different system.

UserRound for both — shipped
Unapproved change to controlsScott Florentino

One mark, one question, one answer. The cost is real and accepted: an added row and an edited one are now visually identical, and the verb survives only in the tooltip and the aria-label. The affordance still separates them — an added row opens with Edit and Remove, an agent's row does not.

The avatar, for both. 12px, filled, strokeWidth={0} as prop and inline style, text-muted-foreground, 4px to the name — one specimen, drawn the same on every marked row. The three alternatives above are kept because the argument for a second glyph is a reasonable one, and this is the record of it being heard and declined.
